# ExpenseFlow — Full-Stack Personal Finance & Expense Tracker

ExpenseFlow is a comprehensive personal finance tracking Android application localized with Bangladeshi Taka (৳ BDT) support, connected to a robust Python Django REST Framework backend.

## ✨ Highlights & Features
- **Bangladeshi Taka (৳) Localization**: Fully localized currency representation throughout the application, with customizable opening balances and support for bKash, Nagad, Rocket, Cash, and Bank Transfer.
- **Smart Budget Engine**: Monthly overall budget and category-specific budgets with visual warning indicators at 80% (Warning Amber) and 100%+ (Danger Red).
- **Interactive Analytics**: 6-month cash flow bar charts, net savings rates, average daily spend calculation, and category expense distributions.
- **CSV Financial Export**: One-tap export of filtered transaction histories directly to CSV with Android Share Sheet integration.
- **Savings Goals**: Goal tracking with visual milestone progress bars and direct deposit contribution logging.
- **Offline-First Architecture**: Android app works seamlessly standalone using Room SQLite database with full CRUD and reactive Flows, while supporting dynamic synchronization with the Django REST backend.
